# DART image sources

The gallery uses artwork and custom-product photographs supplied by the user in `Picture/type/`. Original source files remain unchanged. Optimized web copies and individual source mappings are documented in [artworks/SOURCES.md](artworks/SOURCES.md).

`dart-studio.webp` and `dart-process.webp` are AI-generated studio illustrations. Exact prompts, original generated paths and export notes are in [GENERATED.md](GENERATED.md). Visible page captions distinguish them from the supplied artwork photographs.

The initial museum placeholders have been retired and removed from the website.
